# Использование памяти
* Создайте блок памяти из 5 байт инициализированных “Hello”. 
* При принятии байта по uart перепишите очередной байт в памяти (сначала первый, затем второй и т.д.)
* При нажатии на кнопку – отправьте содержимое памяти через uart в терминал.

Необходимо просимулировать дизайн и показать работоспособность устройства.
