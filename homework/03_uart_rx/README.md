# UART RX
Задача: устройство должно принимать сообщения по UART и если получен ASCII код буквы 'a' (в терминале напечатали букву 'a'), то переключите состояние диода.
Альтернативно: сделайте loopback. Принятый байт отправьте обратно через uart_tx.

Перед выполнением советуется посмотреть примеры 3 (кнопка и работа с асинхронными сигналами) и 4 (работа с uart и терминалом).

# Что необходимо продемонстрировать
1) Реализацию устройства. Разделите его на 2 модуля: uart_rx - модуль принимающий сообщения по UART и top - модуль получающий сообщения от uart_rx и управляющий диодом (или uart_tx для отправки сообщения обратно).
2) 2 работающие симуляции (как в примере uart_tx). 
    - блока uart_rx отдельно.
    - всего устройства вцелом (модуль top)
3) Рабочую прошитую FPGA. 

# Подсказка по реализации
Для приема используйте следующий алгоритм:
При детектировании стартового бита (rx опустился в 0) подождите половину периода бода и проверьте что значение на шине все еще 0 (подтвердите что это действительно стартовый бит а не ошибка). Затем раз в период бода считывайте значение на шине. Таким образом вы будете считывать значение с шины в середине периода что даст достаточную для наших целей помехоустойчивость.
