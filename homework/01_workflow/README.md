# Установка всего необходимого ПО, запуск простого проекта и подготовка к дальнейшей работе.

## Необходимый софт
Скачайте и установите все необходимое ПО для дальнейшей работы:
1. Quartus - САПР для работы с FPGA от Intel.
2. Симулятор:
  2.1 В качестве стандартного решения предлагается Modelsim от Intel. 
  2.2 Для Linux, тех кому не нравится Modelsim и любителей opensource предлагается Icarus Verilog + GTK Wave.
  2.3 В качестве упоминания: наиболее продвинутым opensource симулятором на данный момент является Verilator. Но его использование довольно спецэфично.
Инструкция в [Wiki](https://github.com/BusseAA/FPGA_course/wiki/Software-Installation)

## Что необходимо сделать
Далее воспроизведите действия из примера examples/01_workflow. Пункт Program Flash memory не обязателен и будет рассмотрен более подробно в курсе далее, но можно выполнить если интересно как сделать чтобы FPGA после отключения и включения загружала вашу прошивку а не сбрасывалась (особенно рекомендуется тем у кого стандартная прошивка пищит).

## Что необходимо для сдачи
1. Показать что симуляции проходит корректно.
2. Показать что в Quartus сборка проекта проходит без ошибок.
3. Показать что прошивка загружается на плату и работает.
